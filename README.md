
# Netraa (`Netraa.app`)

> **Autonomous AI Healthcare Access Infrastructure & Luxury Medical Travel Engine**  
> Connecting US, European, and global patients to India's premier JCI & NABH-accredited super-specialty hospitals with **1/5th the US cost (5X savings)**.

---

## 🚀 Overview

Netraa solves cross-border healthcare fragmentation. Through an autonomous AI clinical triage assistant, an instant transparent procedure cost calculator, and direct virtual consultation pipelines, Netraa guides medical travelers from preliminary self-diagnosis to fast-track Medical M-Visa processing and 5-star recovery accommodations in India's top medical hubs: **Bengaluru, Delhi NCR, Mumbai, Chennai, and Kochi**.

---

## 🌟 Key Features

- **Autonomous AI Triage Concierge:** Intelligent conversational agent for matching aesthetic, orthopedic, and oncology inquiries to board-certified super-specialists.
- **Dynamic 5X Savings Engine:** Side-by-side cost calculator comparing standard US Out-Of-Pocket / PPO expenses with comprehensive Indian packages in multi-currency (`USD`, `EUR`, `GBP`).
- **Curated Super-Specialist Network:** Verified credentials across MCh, MS, FACS, and FRCS surgeons operating in JCI/NABH hospitals (Fortis, Apollo, Max, Manipal).
- **Luxury Post-Operative Suites:** Seamless recovery coordination with luxury hotel partners (The Oberoi, Taj, ITC Grand, The Leela).
- **Fast-Track Medical M-Visa Concierge:** End-to-end documentation triage delivering hospital invitation letters within 48 to 72 hours.

## 🛠️ Tech Stack Options

Netraa can be deployed as either a **Next.js / React (Tailwind CSS)** frontend on **Vercel** or as a rapid data app via **Streamlit / Python**.

### Primary Web Architecture (Recommended for Vercel)
- **Framework:** Next.js (App Router) or Vite + React
- **Styling:** Tailwind CSS + Lucide React Icons
- **AI Orchestration:** Anthropic Claude 3.5 / OpenAI GPT-4o via Vercel AI SDK
- **Hosting & Edge Routing:** Vercel

### Alternative Rapid Prototyping Architecture (Streamlit)
- **Framework:** Streamlit (`Python 3.10+`)
- **Components:** `st.chat`, `pandas`, `altair` / `plotly`
- **Deployment:** Streamlit Community Cloud / Vercel Python Serverless
